# Security

Report vulnerabilities privately through [GitHub security advisories](https://github.com/usemont/skills/security/advisories/new). Do not publish credentials, private project payloads, originals, or executable downloads in an issue.

This repository contains skills and recipes, not the Mont runtime. Include the affected file, revision, Mont version, and a minimal reproduction using synthetic or owned data. Do not send access tokens or confidential media. There is no guaranteed response time or bug bounty.

Never bypass Gatekeeper or use an unsigned internal executable to follow these instructions. Review project bundles before sharing: they contain original assets as well as metadata.
