# Contributing

Open an issue for bugs or recipe proposals; submit a pull request for a focused change. Include the Mont version, OS, exact command, expected behavior, and observed result. Redact credentials and private project material. Do not attach user media without permission.

Contribute only original material you can license under Apache-2.0. No private Mont source, internal executables, copied third-party skills, or unlicensed media. User assets are not relicensed by a recipe.

For recipe changes, run the real-binary check documented in README.md using an authorized executable and a new output directory. Record the exact binary version and result. If you cannot run it, say so; do not substitute mock CLI output. Do not commit generated workspaces, bundles, logs, or binaries.

Keep examples within the current CLI contract: native project editing, asset registration, validation, and offline bundles. Do not promise timeline composition or rendered video.

For security concerns, follow [SECURITY.md](SECURITY.md), not a public issue.
