# Contributing

Open an issue for bugs or skill proposals; submit a pull request for a focused change. Include the Mont version, OS, exact command, expected behavior, and observed result. Redact credentials and private project material. Do not attach user media without permission.

Contribute only original material you can license under Apache-2.0. No private Mont source, internal executables, copied third-party skills, or unlicensed media. User assets are not relicensed by a recipe.

For instruction changes, run the documented commands with the supported release executable and a new output directory. For video workflows, validate the resulting project, inspect the MP4, and fully decode it as documented in [SKILL.md](skills/mont-project/SKILL.md). Record the exact binary version and result. If you cannot run it, say so; do not substitute mock CLI output. Do not commit generated workspaces, bundles, logs, or binaries.

Keep examples within the current CLI contract. Use native Mont workflows for repeatable video generation; contribute workflow and template assets to [usemont/awesome-workflows](https://github.com/usemont/awesome-workflows), not a second copy here.

For security concerns, follow [SECURITY.md](SECURITY.md), not a public issue.
